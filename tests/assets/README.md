# Test assets

Models from the [Khronos glTF Sample Assets](https://github.com/KhronosGroup/glTF-Sample-Assets), unmodified.

| File | What it covers | Author | License |
|---|---|---|---|
| `gltf/Box.glb` | One mesh, one material | Cesium | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |
| `gltf/BoxTextured.glb` | Texture coordinates and an embedded texture | Cesium | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |
| `gltf/draco/Box.gltf`, `Box.bin` | `Box` with its mesh compressed by Draco (`KHR_draco_mesh_compression`) | Cesium | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |
| `gltf/CesiumMilkTruck.glb` | Node hierarchy, a mesh shared by two nodes, several materials and textures | Cesium | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |
| `gltf/SimpleMeshes.gltf` | A mesh shared by two nodes, no material, `.gltf` with embedded buffers | Marco Hutter | [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) |

The Cesium logo in the textures of `BoxTextured` and `CesiumMilkTruck` is a trademark of Cesium.
